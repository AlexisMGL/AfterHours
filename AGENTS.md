# Afterhours — instructions pour les agents

Préserver les quatre expériences et leurs routes. Le dépôt utilise Vite, TypeScript strict et une publication statique Netlify ; ne pas créer un projet distinct pour modifier une app.

Pour Malagasy Adventure, lire [les consignes produit et pédagogiques](src/malagasy/AGENTS.md) avant de modifier le parcours, le contenu, les illustrations ou les interactions. Elles conservent les retours explicites de l’utilisateur et s’appliquent aussi aux changements du catalogue liés à cette app.

Les demandes ultérieures de l’utilisateur prévalent sur ces consignes. Garder les identifiants persistants et les sauvegardes compatibles ; vérifier les moteurs et les parcours affectés avant livraison.
